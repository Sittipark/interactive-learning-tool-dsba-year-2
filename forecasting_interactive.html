Decision Framework

แผนผังตัดสินใจ: ดูกราฟแบบนี้ เลือกหยิบสูตรไหนดี?

ใช้คำถาม 3 สเต็ปง่ายๆ ในการกรองโมเดลที่ถูกต้องตามลักษณะของอนุกรมเวลา

1

ตรวจหาทิศทางหลัก (Trend)

เส้นกราฟพุ่งขึ้นหรือดิ่งลงต่อเนื่องอย่างมีนัยสำคัญหรือไม่?

❌ ไม่มี Trend (นิ่ง/สวิงคงที่): → กลุ่ม Stationary: Naïve, Simple Avg, SMA, SES
✅ มี Linear Trend: → ก้าวต่อไปสู่การตรวจหาฤดูกาล (Step 2)
2

ตรวจหาคลื่นฤดูกาล (Seasonality)

มีรอบการพีคหรือดิ่งซ้ำเดิมทุกไตรมาสหรือทุกเดือนหรือไม่?

มี Trend อย่างเดียว (ไม่มีฤดูกาล): → Double Moving Average (DMA) หรือ Brown's Double Exp
มีทั้ง Trend + Seasonality: → ใช้ Holt-Winters Method (พิจารณาขนาดคลื่นใน Step 3)
3

ตัดสินใจเลือกสูตร Holt-Winters

ดูความสูงของยอดคลื่น เมื่อระยะเวลาผ่านไปและยอดขายรวมสูงขึ้น

คลื่นกว้างเท่าเดิมคงที่: → Holt-Winters Additive ($F = L + bm + S$)
คลื่นยิ่งนานยิ่งขยายตัวสูงใหญ่: → Holt-Winters Multiplicative ($F = (L + bm) \times S$)

สรุปสูตรคำนวณและสัญลักษณ์สำคัญ (Comprehensive Formula Sheet)

1. กลุ่ม Averaging Methods (Horizontal)

Equal Weights
Naïve Method:
$$F_{t+1} = Y_t$$

ใช้ค่าจริงคาบเวลาล่าสุด เป็นค่าพยากรณ์คาบถัดไปทันที

Simple Moving Average (SMA):
$$F_{t+1} = \frac{Y_t + Y_{t-1} + \dots + Y_{t-N+1}}{N}$$

เฉลี่ย $N$ คาบล่าสุด โดยข้อมูลเก่าสุดจะหลุดออกจากการคำนวณ

Weighted Moving Average (WMA):
$$F_{t+1} = \sum_{i=1}^N w_i Y_{t-i+1} \quad \text{โดยที่} \quad \sum w_i = 1$$

ให้น้ำหนักกับข้อมูลใหม่มากกว่าข้อมูลอดีต

2. Exponential Smoothing Methods

Unequal Weights
Single Exponential Smoothing (SES):
$$F_{t+1} = \alpha Y_t + (1 - \alpha)F_t$$

$\alpha$ (Smoothing Constant) อยู่ระหว่าง 0 ถึง 1 นิยม 0.1 - 0.2

Brown's Double Exponential Smoothing (Linear Trend):
$$S_t(1) = \alpha Y_t + (1-\alpha)S_{t-1}(1)$$ $$S_t(2) = \alpha S_t(1) + (1-\alpha)S_{t-1}(2)$$ $$a_t = 2S_t(1) - S_t(2), \quad b_t = \frac{\alpha}{1-\alpha}[S_t(1) - S_t(2)]$$ $$F_{t+m} = a_t + b_t(m)$$

ปรับเรียบ 2 ชั้น เหมาะกับข้อมูลมีแนวโน้มเชิงเส้นแต่ไม่มีฤดูกาล

3. Holt-Winters Method (Trend & Seasonality)

3 Parameters: $\alpha$ (Level), $\gamma$ (Trend), $\beta$ (Season)
รูปแบบการบวก (Additive Model):

เมื่อผลกระทบจากฤดูกาลมีขนาดคงที่ ไม่ขึ้นกับระดับยอดขาย

$$L_t = \alpha(Y_t - S_{t-s}) + (1-\alpha)(L_{t-1} + b_{t-1})$$
$$b_t = \gamma(L_t - L_{t-1}) + (1-\gamma)b_{t-1}$$
$$S_t = \beta(Y_t - L_t) + (1-\beta)S_{t-s}$$
$$F_{t+m} = L_t + b_t(m) + S_{t-s+m}$$
รูปแบบการคูณ (Multiplicative Model):

เมื่อผลกระทบจากฤดูกาลขยายตัวเป็นสัดส่วนตามยอดขายรวมที่โตขึ้น

$$L_t = \alpha\left(\frac{Y_t}{S_{t-s}}\right) + (1-\alpha)(L_{t-1} + b_{t-1})$$
$$b_t = \gamma(L_t - L_{t-1}) + (1-\gamma)b_{t-1}$$
$$S_t = \beta\left(\frac{Y_t}{L_t}\right) + (1-\beta)S_{t-s}$$
$$F_{t+m} = (L_t + b_t m) \times S_{t-s+m}$$

4. เกณฑ์วัดความคลาดเคลื่อนของการพยากรณ์ (Forecast Error Metrics)

เปรียบเทียบโมเดล เพื่อเลือกตัวที่ Error ต่ำสุด
Mean Absolute Error (MAE / MAD):
$$MAE = \frac{\sum_{t=1}^n |Y_t - F_t|}{n}$$

ผลต่างสัมบูรณ์เฉลี่ย ไม่คำนึงถึงเครื่องหมายบวกหรือลบ

Mean Squared Error (MSE):
$$MSE = \frac{\sum_{t=1}^n (Y_t - F_t)^2}{n}$$

ยกกำลังสอง ทำให้ข้อผิดพลาดใหญ่ถูกลงโทษหนักมาก

Mean Absolute Percentage Error (MAPE):
$$MAPE = \frac{100\%}{n} \sum_{t=1}^n \left|\frac{Y_t - F_t}{Y_t}\right|$$

บอกเป็นร้อยละ เทียบง่ายแม้ข้อมูลคนละสเกล (< 10% ยอดเยี่ยม)
